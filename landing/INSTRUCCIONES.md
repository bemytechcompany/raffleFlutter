# 🚀 Instrucciones para Ejecutar la Landing Page

## Requisitos Previos
- Node.js 18.0+ instalado
- npm o yarn como gestor de paquetes

## 📋 Pasos para Ejecutar

### 1. Instalar Dependencias
```bash
cd landing
npm install
```

### 2. Ejecutar en Desarrollo
```bash
npm run dev
```

### 3. Abrir en Navegador
Abre http://localhost:3000 en tu navegador

## 🔧 Personalización

### Colores
Edita `tailwind.config.js` para cambiar colores:
```javascript
colors: {
  'raffle-green': '#4CAF50',
  'raffle-green-light': '#68D391',
}
```

### Contenido
Modifica el contenido en los archivos de componentes:
- `components/sections/HeroSection.tsx`
- `components/sections/FeaturesSection.tsx`
- `components/sections/DownloadSection.tsx`
